# w5 Hook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install Claude Code hooks that enqueue classification jobs, a detached runner that classifies session windows into traces, activities and quests through a model behind an interface, and the hand-back loop (watch, ask, budget, expiry, review), all without ever blocking a session.

**Architecture:** Hooks are tiny shell entry points calling `tempad w5 enqueue|context`; jobs live in a `w5_jobs` table; `tempad w5 run` drains jobs, builds a window from `claude_messages`, calls a `Classifier` (Anthropic API via `fetch`, injectable), and appends intent events through the plan-1 API. Question state machine lives in `src/w5/questions.ts` and is pure over the projection tables.

**Tech Stack:** Bun 1.3, `bun:sqlite`, `fetch` to `https://api.anthropic.com/v1/messages` (no SDK), TypeScript strict, `bun test`. Hooks are bash + the `tempad` binary.

**Spec:** `docs/specs/2026-09-05-intent-model-and-w5-hook-design.md`, sections "The w5 hook", "Classifier run", "Hand-back rules", "`tempad review`", "Error handling", "Testing". Plan 1 (`docs/plans/2026-09-05-intent-core.md`) must be merged first; this plan consumes `src/intent/api.ts`, `src/intent/config.ts` (`W5Config`), `src/intent/store.ts`, and the projections.

## Global Constraints

- Same as plan 1: bun only, full-word identifiers, no `any`, no non-null assertions, gates under `flock /tmp/tempad-heavy.lock`, commits `type(w5): summary`, one per task.
- Hook entry points exit 0 always; errors go to `TEMPAD_HOME/logs/w5.log`.
- `ANTHROPIC_API_KEY` is required only when a model call actually happens; `loadConfig` does not require it (hooks must run without it and just log).
- Tests never call the network: `Classifier` is an interface; tests use a fake returning canned JSON.
- Do not modify `src/collect/*` beyond exporting a `syncOneSessionFile(database, config, filePath)` function from the Claude collector (Task 3) with no behavior change to the existing sync.

### Task 1: Jobs table, enqueue, throttle, claim

**Files:**

- Create: `packages/core/src/w5/jobs.ts`, `packages/core/src/db/migrations/0005_w5.sql`

**Interfaces:**

- Table `w5_jobs(id INTEGER PK, session_id TEXT NOT NULL, kind TEXT NOT NULL 'classify', forced INTEGER NOT NULL, requested_at TEXT NOT NULL, claimed_at TEXT, finished_at TEXT, state TEXT NOT NULL 'queued'|'running'|'done'|'failed', error TEXT)`; table `w5_runs(session_id TEXT PK, last_run_at TEXT NOT NULL, last_message_ts TEXT)`; table `w5_quiet(until TEXT NOT NULL)` single row.
- `enqueueJob(database, input: { sessionId: string; forced: boolean; now?: string; throttleMinutes: number }): { enqueued: boolean; reason?: "throttled" | "duplicate" }` — throttled when not forced and `w5_runs.last_run_at` is younger than `throttleMinutes`; duplicate when a queued job for that session exists (a forced request upgrades an existing queued job to forced instead of adding one).
- `claimNextJob(database, now?)`: oldest queued → running, returns it or null. `completeJob(database, id, lastMessageTs)` sets done and upserts `w5_runs`. `failJob(database, id, error)`.

```ts
// packages/core/test/w5/jobs.test.ts
import { describe, expect, test } from "bun:test";
import { openDatabase } from "../../src/db/database";
import { claimNextJob, completeJob, enqueueJob, failJob } from "../../src/w5/jobs";

describe("w5 jobs", () => {
  test("enqueue, throttle, duplicate upgrade, claim, complete", () => {
    const database = openDatabase(":memory:");
    expect(enqueueJob(database, { sessionId: "s1", forced: false, now: "2026-09-05T10:00:00.000Z", throttleMinutes: 10 }).enqueued).toBe(true);
    expect(enqueueJob(database, { sessionId: "s1", forced: false, now: "2026-09-05T10:01:00.000Z", throttleMinutes: 10 })).toEqual({ enqueued: false, reason: "duplicate" });
    expect(enqueueJob(database, { sessionId: "s1", forced: true, now: "2026-09-05T10:01:00.000Z", throttleMinutes: 10 })).toEqual({ enqueued: false, reason: "duplicate" });
    expect((database.query("SELECT forced FROM w5_jobs").get() as { forced: number }).forced).toBe(1);
    const job = claimNextJob(database, "2026-09-05T10:02:00.000Z");
    expect(job?.sessionId).toBe("s1");
    expect(claimNextJob(database)).toBeNull();
    completeJob(database, job?.id ?? 0, "2026-09-05T10:01:30.000Z");
    expect(enqueueJob(database, { sessionId: "s1", forced: false, now: "2026-09-05T10:05:00.000Z", throttleMinutes: 10 })).toEqual({ enqueued: false, reason: "throttled" });
    expect(enqueueJob(database, { sessionId: "s1", forced: true, now: "2026-09-05T10:05:00.000Z", throttleMinutes: 10 }).enqueued).toBe(true);
    expect(enqueueJob(database, { sessionId: "s1", forced: false, now: "2026-09-05T10:13:00.000Z", throttleMinutes: 10 }).enqueued).toBe(false);
  });

  test("failJob records the error and frees the queue", () => {
    const database = openDatabase(":memory:");
    enqueueJob(database, { sessionId: "s2", forced: true, throttleMinutes: 10 });
    const job = claimNextJob(database);
    failJob(database, job?.id ?? 0, "boom");
    expect((database.query("SELECT state, error FROM w5_jobs").get() as { state: string; error: string }).state).toBe("failed");
  });
});
```

### Task 2: Classifier interface, result schema, prompt builder, Anthropic client

**Files:**

- Create: `packages/core/src/w5/classifier.ts`, `packages/core/src/w5/prompt.ts`

**Interfaces:**

- `interface ClassifierWindow { sessionId: string; title: string | null; cwd: string | null; gitBranch: string | null; org: string; project: string; messages: { ts: string; role: string; text: string }[]; openQuests: { id: string; title: string; objective: string | null; lastActivityAt: string | null }[]; previousTrace: { activityId: string; what: string; questId: string | null } | null }`.
- `interface ClassifierSegment { startedAt: string; endedAt: string; what: string; why: string; matchedQuest: string | null; proposedQuest: { title: string; objective: string; commitment: "promised" | "personal" | "exploratory" } | null; matchedActivity: string | null; isSwitch: boolean; trigger: string | null; confidence: number; questions: ("which_quest" | "why" | "trigger")[] }`; `interface ClassifierResult { segments: ClassifierSegment[] }`.
- `validateResult(raw: unknown): ClassifierResult` throws with a message listing every problem (missing field, bad type, confidence outside 0..1, unknown question kind, timestamps outside the window).
- `interface Classifier { classify(window: ClassifierWindow): Promise<ClassifierResult> }`.
- `class AnthropicClassifier implements Classifier { constructor(options: { apiKey: string; model: string; fetch?: typeof fetch }) }` posting to `/v1/messages` with `anthropic-version: 2023-06-01`, `max_tokens: 2048`, system prompt from `prompt.ts`, and a user message containing the window rendered as compact text; on invalid JSON it retries once with the validation error appended to the user message, then throws.
- `buildSystemPrompt(): string` and `buildUserPrompt(window): string` in `prompt.ts`. The system prompt states the purpose (self-awareness, not surveillance), the JSON schema verbatim, the rule that `isSwitch` means the objective changed versus `previousTrace`, that `trigger` must be quoted or closely paraphrased from the transcript, and that `questions` lists only what cannot be told from the window.

import { describe, expect, test } from "bun:test";
import { AnthropicClassifier, validateResult, type ClassifierWindow } from "../../src/w5/classifier";
import { buildUserPrompt } from "../../src/w5/prompt";

const window: ClassifierWindow = {
  sessionId: "s", title: "marko-ui", cwd: "/w/marko-ui", gitBranch: "main", org: "personal", project: "marko-ui",
  messages: [
    { ts: "2026-09-04T15:00:00.000Z", role: "user", text: "fix the walk order bug" },
    { ts: "2026-09-04T15:20:00.000Z", role: "user", text: "wait, what does Astryx do for agents? compare it with ours" },
  ],
  openQuests: [{ id: "Q1", title: "Ship marko-ui", objective: "86 components", lastActivityAt: "2026-09-04T14:00:00.000Z" }],
  previousTrace: { activityId: "A1", what: "fixing walk order", questId: "Q1" },
};

const good = { segments: [
  { startedAt: "2026-09-04T15:00:00.000Z", endedAt: "2026-09-04T15:20:00.000Z", what: "fix walk order", why: "ship marko-ui", matchedQuest: "Q1", proposedQuest: null, matchedActivity: "A1", isSwitch: false, trigger: null, confidence: 0.9, questions: [] },
  { startedAt: "2026-09-04T15:20:00.000Z", endedAt: "2026-09-04T15:20:00.000Z", what: "compare Astryx", why: "unknown", matchedQuest: null, proposedQuest: { title: "Compare Astryx", objective: "see what they claim", commitment: "exploratory" }, matchedActivity: null, isSwitch: true, trigger: "what does Astryx do for agents?", confidence: 0.6, questions: ["which_quest"] },
] };

describe("classifier", () => {
  test("validateResult accepts a good result and rejects a bad one listing problems", () => {
    expect(validateResult(good).segments.length).toBe(2);
    expect(() => validateResult({ segments: [{ ...good.segments[0], confidence: 2, questions: ["nope"] }] })).toThrow(/confidence.*questions|questions.*confidence/s);
  });

  test("user prompt contains messages, open quests and previous trace", () => {
    const text = buildUserPrompt(window);
    expect(text).toContain("Astryx");
    expect(text).toContain("Ship marko-ui");
    expect(text).toContain("fixing walk order");
  });

  test("anthropic client parses JSON text and retries once on invalid output", async () => {
    let calls = 0;
    const fakeFetch = (async () => {
      calls += 1;
      const body = calls === 1 ? { content: [{ type: "text", text: "not json" }] } : { content: [{ type: "text", text: JSON.stringify(good) }] };
      return new Response(JSON.stringify(body), { status: 200, headers: { "content-type": "application/json" } });
    }) as unknown as typeof fetch;
    const classifier = new AnthropicClassifier({ apiKey: "k", model: "m", fetch: fakeFetch });
    const result = await classifier.classify(window);
    expect(calls).toBe(2);
    expect(result.segments[1]?.isSwitch).toBe(true);
  });

  test("anthropic client fails after the retry", async () => {
    const fakeFetch = (async () => new Response(JSON.stringify({ content: [{ type: "text", text: "{" }] }), { status: 200 })) as unknown as typeof fetch;
    const classifier = new AnthropicClassifier({ apiKey: "k", model: "m", fetch: fakeFetch });
    await expect(classifier.classify(window)).rejects.toThrow();
  });
});

- Modify: `packages/core/src/cli.ts` (dispatch `w5`, `quiet`, `review`)

**Interfaces:**

- `runOnce(database, config, intentConfig, classifier, options: { now?: string; log: (line: string) => void }): Promise<{ ran: boolean; sessionId?: string; summary?: AppliedSummary }>`: claim → `syncOneSessionFile` → `buildWindow` (since `w5_runs.last_message_ts`) → classify → `applyResult` → `advanceQuestions` (turns since last run = count of user messages in the window) → `completeJob`; any throw → `failJob` + log, never rethrow.
- `drain(...)` loops `runOnce` until no job; `tempad w5 run [--detached]` acquires `TEMPAD_HOME/w5.lock` (exclusive create; stale after 30 min), and with `--detached` spawns itself with `Bun.spawn({ cmd, detached: true, stdio: ["ignore", logFile, logFile] })` and exits.
- `tempad w5 enqueue --session <id> [--forced]` (reads `throttle_minutes` from config; prints nothing; exit 0 always) and then spawns `w5 run --detached` when the lock is free.
- `tempad w5 context --session <id>` prints the `additionalContext` text for `asked` questions of that session (from `hooks.ts` `buildAdditionalContext`, Task 7) or nothing.
- `tempad quiet <duration>` (`2h`, `30m`) writes `w5_quiet.until`. `tempad review` lists expired questions, unconfirmed quests, traces with `confidence < 0.5`, and a 10% sample of `classified_by = 'assistant'` traces, oldest first, one line each with the command that resolves it.
